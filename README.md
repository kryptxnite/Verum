# 📝 Verum - Blog Platform (Django)

A modern blog platform built with Django, featuring clean UI and full backend functionality.

## 🚀 Features
- Create, edit, delete posts
- Search functionality
- Tagging
- Responsive design
- Admin panel
- Clean and minimal UI (Typeright template)

## 🛠 Tech Stack
- Python
- Django
- PostgreSQL
- HTML / CSS / JS

## ⚙️ Installation

```bash
git clone https://github.com/kryptxnite/Verum.git
cd Verum
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
